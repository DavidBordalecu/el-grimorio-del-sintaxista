Antes de empezar: cómo trabajar

Compilar también es parte del aprendizaje

01

Copiá el código inicial

Cada lección tiene un botón «Copiar código inicial». Reemplazá los huecos `______` con tu código.

02

Compilalo fuera del juego

Si el compilador se queja, leé el error y corregilo. Esa es la práctica real de Rust.

03

Copiá la salida exacta

Cuando el programa corra, pegá lo que imprimió en el campo de la lección.

04

Comprobá y seguí

Si coincide con la salida esperada, se rompe el sello, sumás XP y se abre la siguiente lección.

Desde tu PC

  1. Instalá el compilador con rustup.rs.
  2. Guardá el código en main.rs.
  3. En una terminal ejecutá rustc main.rs && ./main.

En Windows usá rustc main.rs && main.exe. Si preferís, también podés crear un proyecto con cargo new.

En una web

  1. Abrí Rust Playground, el sitio oficial.
  2. Pegá el código completado y pulsá Run.
  3. Copiá la salida de la pestaña Stdout y pégala en la lección.

No hace falta iniciar sesión. Podés cambiar entre debug y release; para estas lecciones alcanza con debug.

La idea es practicar escribiendo código. No pidas el programa terminado a otra IA: completá los huecos y usá las pistas del grimorio si te trabás.
