01

¿De qué va todo esto?

La idea en una página

Es una aplicación web educativa con forma de librojuego. La pantalla simula un grimorio abierto: a la izquierda tenés la Crónica —la historia, el objetivo y el Espíritu Guía— y a la derecha el Grimorio, un editor donde escribís JavaScript de verdad.

Cada escena plantea un problema narrativo que se resuelve con un concepto de programación: declarar una constante para sellar una llave, decidir entre sigilo o ataque con un if, separar pociones con filter() o construir un objeto JSON para un oráculo. El código se ejecuta en un hilo aparte y se comprueba automáticamente. Cuando el sello cede, ganás experiencia y un hechizo nuevo para tu inventario.

El objetivo es que aprender no se sienta como una lista de ejercicios: cada línea que escribís tiene consecuencias dentro de una historia, los errores se traducen a lenguaje narrativo y la ayuda llega en forma de pistas, nunca como la respuesta copiada.

Lo que ves

  • Dos paneles que imitan las páginas de un libro.
  • Objetivos concretos por escena.
  • Consola con tus console.log() y errores explicados.
  • Inventario de conceptos desbloqueados.

Lo que pasa por debajo

  • Tu código viaja a un Web Worker aislado.
  • Un temporizador de 2000 ms corta bucles infinitos.
  • Se evalúan variables, expresiones y patrones del código.
  • El progreso persiste en localStorage.
02

El contexto de la historia

Quién sos, dónde estás y por qué importa

En algún momento los saberes de la programación dejaron de estar en libros y quedaron grabados como runas vivas dentro de un grimorio custodiado por la Orden de los Sintaxistas. Cada runa era una instrucción: las había para guardar valores, para decidir caminos, para repetir tareas y para invocar respuestas de más allá del abismo.

Un día el grimorio se fragmentó. Sus páginas se dispersaron por cinco regiones y la Orden se redujo a vocablos olvidados. Vos sos el último aprendiz con acceso al libro. Para recomponerlo debés recuperar cada fragmento resolviendo el acertijo que lo guarda. No se trata de memorizar comandos: se trata de entender qué problema resuelve cada runa.

La aventura empieza en la Aldea de las Runas, donde un guardián de piedra exige nombrar lo que no debe cambiar. Sigue por sendas que se bifurcan y catacumbas que devuelven el eco, y culmina ante el Oráculo del Abismo, que solo responde a peticiones estructuradas. Cada paso que das en la crónica es un paso en tu aprendizaje real de JavaScript.

«Nombra lo que no debe cambiar y suelta lo que aún puede fluctuar.» — El Guardián del Puente

En este MVP vas a recorrer las tres escenas del Acto I y una escena de apertura del Acto V. Los actos II, III y IV están diseñados y documentados, pero todavía no son jugables: la primera versión se concentra en los fundamentos y en el primer contacto con el pensamiento de prompts.

03

Cómo se juega

Seis pasos, de la lectura al siguiente sello

  1. 1

    Leé la página izquierda

    Arriba ves el acto, tu energía, nivel y experiencia. Abajo, la narración y el recuadro con el objetivo del sello.

  2. 2

    Observá el código inicial

    El editor ya trae las variables que la escena te da. No las redeclares: trabajá con lo que está escrito.

  3. 3

    Escribí tu conjuro

    Usás JavaScript real. La tecla Tab inserta dos espacios en vez de mover el foco. Tus borradores se guardan solos.

  4. 4

    Invocá el conjuro

    El botón envía el código al Web Worker. Aparecen tus console.log(), los errores y el resultado de la validación.

  5. 5

    Pedí ayuda al Espíritu Guía

    Escribí una pregunta con contexto. Si pedís la respuesta directa, se niega; si nombrás el concepto, te da una pista.

  6. 6

    Rompé el sello y seguí

    Sumás XP, desbloqueás un hechizo en el inventario y pulsás «Seguir la crónica» para abrir la siguiente página.

04

Los cinco actos

El plan de estudios disfrazado de aventura

Acto y ambientación Conceptos de JavaScript Reto jugable Estado en el MVP
I · La Aldea de las Runas Variables (const, let), tipos primitivos, operadores y template literals. Sellar la llave, equilibrar suministros y decidir entre sigilo o ataque. 3 escenas jugables
II · El Bosque de las Bifurcaciones if / else, switch, operadores lógicos y Math.random(). Evaluar la energía para elegir conducta frente a enemigos. Planificado
III · Las Catacumbas del Eco Bucles for / while, arrays y métodos push, filter, map. Filtrar frascos para conservar solo pociones curativas seguras. Planificado (la mecánica de filter ya aparece en el Acto I)
IV · La Torre de los Autómatas Funciones, alcance, objetos literales y manipulación del DOM. Construir funciones de equipamiento que actualicen la ficha del héroe. Planificado
V · El Oráculo del Abismo Asincronía (fetch, async/await), JSON, try/catch y prompt engineering. Configurar rol, formato e instrucción para recibir una respuesta válida. 1 escena jugable

El MVP cubre el Acto I completo más una escena introductoria del Acto V, tal como especifica el SDD. El resto del plan queda como hoja de ruta.

05

Qué vas a aprender

Conceptos que se vuelven hechizos

{ }

Variables

const guarda un valor que no se reasigna; let guarda uno que puede cambiar. Elegir bien entre ellos es el primer sello.

↳

Decisión

if / else evalúa una condición y abre dos caminos. Los operadores de comparación devuelven verdadero o falso.

[ ]

Colecciones

Un array guarda listas. Con filter() o un bucle for podés quedarte solo con lo que necesitás.

</>

Ejecución y errores

console.log() deja huellas en la consola. Los errores de sintaxis o referencia se explican dentro de la ficción.

✧

Pensamiento socrático

El Espíritu Guía evalúa cómo preguntás. Aprender a formular dudas concretas es parte del oficio.

{JSON}

Prompts y JSON

Una petición útil define rol, formato e instrucción. JSON es la estructura con la que el Oráculo acepta responder.

06

Detalles técnicos y preguntas rápidas

Lo que conviene saber antes de abrir el libro

Stack y arquitectura

  • HTML5 semántico, CSS3 puro y JavaScript ES6 con módulos.
  • Cero frameworks, bundlers o dependencias obligatorias.
  • Módulos separados: estado, narrativa, sandbox, oráculo e historias.
  • Diseño de libro abierto en escritorio y apilado en móvil.

Ejecución y seguridad

  • El código corre en un Web Worker: no puede tocar el DOM.
  • Timeout estricto de 2 segundos ante bucles infinitos.
  • Es un sandbox educativo, no una barrera para código hostil.
  • Hay que servirlo por HTTP/HTTPS; file:// no funciona.
¿Necesito instalar algo?
No. Con python3 -m http.server 8000 dentro de la carpeta alcanza. También funciona en GitHub Pages o itch.io.
¿Qué pasa si hago un bucle infinito?
El hilo se termina a los 2 segundos y la consola lo explica como un «bucle temporal infinito». Tu progreso no se pierde.
¿El Espíritu Guía es una IA real?
No en esta versión: es un tutor simulado por palabras clave. El Acto V te enseña a estructurar la petición para una IA real.
¿Puedo perder mi progreso?
Solo si limpiás los datos del navegador. Escenas, XP, inventario y borradores viven en localStorage.
