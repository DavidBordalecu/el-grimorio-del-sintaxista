Antes de empezar: cómo trabajar

Cuatro pasos para cada lección

01

Copiá el código inicial

Cada lección tiene un botón «Copiar código inicial». Los huecos con `______` se reemplazan con tu código.

02

Ejecutalo fuera del juego

Usá tu computadora o una plataforma online. El grimorio no ejecuta este código: lo hacés vos.

03

Copiá la salida exacta

La consola muestra un resultado; lo pegás en el campo de la lección, sin agregar texto extra.

04

Comprobá y seguí

Si coincide con la salida esperada, se rompe el sello, sumás XP y se abre la siguiente lección.

Desde tu PC

  1. Instalá Python 3 desde python.org/downloads.
  2. Guardá el código en un archivo, por ejemplo leccion.py.
  3. En una terminal, dentro de esa carpeta, ejecutá python3 leccion.py.

En Windows el comando suele ser python leccion.py.

En una web

  1. Abrí Programiz Python Online Compiler.
  2. Pegá el código inicial completado y pulsá Run.
  3. Copiá el texto de salida y pégalo en la lección.

También podés usar Replit u otro intérprete online; la salida debe ser la misma.

La idea es practicar escribiendo código. No pidas el programa terminado a otra IA: completá los huecos y usá las pistas del grimorio si te trabás.
